# Livro de códigos v1.2: exemplos sintéticos

O livro de códigos (`LIVRO-DE-CODIGOS-v1.2.md`) foi congelado antes da codificação e não é
alterado. Os exemplos abaixo foram **escritos para ilustração**: não são intervenções reais,
que contêm detalhes de um produto clínico e não são publicadas (LGPD).

| Categoria | Exemplo sintético |
|---|---|
| correção | "O filtro de data está ignorando o fuso; ajuste para considerar America/Recife." |
| rejeição | "Desfaça essa migração, não vamos seguir por esse caminho." |
| redirecionamento | "Em vez de criar um serviço novo, reaproveite o módulo de agenda existente." |
| solicitação | "Agora crie os testes de integração para esse endpoint." |
| dúvida | "Por que você usou uma transação aqui?" |
| aprovação | "Pode fazer o commit." |
| avaliação | "Ficou bem mais legível assim." |
| relato | "Já atualizei o arquivo de seeds manualmente, considere essa versão." |

Regras de desempate (do livro de códigos): pedido com apontamento de erro → correção;
relato com pedido ou pergunta → o que é pedido ou perguntado, com relato como secundária.
